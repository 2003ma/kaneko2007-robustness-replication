# Analysis Paper

This directory contains the main plotting scripts for generating publication-ready figures. Each subdirectory focuses on a specific analysis aspect of evolutionary robustness under different mutation strengths (sigma).

## Directory Overview

### `fitness/`
Visualizes best and worst fitness trajectories across generations for multiple sigma values.

**Scripts:**
- `plot_best_by_sigma.py` — Overlay best fitness vs generation (by sigma)
- `plot_worst_by_sigma.py` — Overlay worst fitness vs generation (by sigma)

**Usage:**
```bash
python3 plot_best_by_sigma.py \
  --input-dir ../../evo_sim/results/data_sigma_only/ver1 \
  --sigmas 0.005 0.1 0.4 0.6 1.0\
  --output best_fitness.pdf
```

### `fitness_dist_random_initial/`
Fitness distribution analysis with random initial conditions.

**Script:**
- `plot_fitness_distribution_by_sigma.py` — Overlay fitness histograms by sigma value

**Data Expected:**

- CSV files in the `fitness/` subdirectory with the filename pattern:
  `trial_fitness_gen=200_ind=0_sigma=*_seed=...csv`
- Move the individual you wish to analyze from the `allx` directory (within the corresponding `sigma` folder in `evo_sim/results/ver1/`) to the `fitness` directory.

**Data preparation note:**

The CSV files in the `fitness/` directory are copied from the `allx/` directory of the simulation results, for example:

sims/evo_sim/results/ver1/sigma_0.040/trials10000/t1=80_t2=90_trials10000_dt0.050_allJ/gen_200_all_individuals/allx/
Only the CSV files corresponding to ind=0 are placed in the fitness/ directory.

### `under_noise_fitness/`

Analyzes robustness under simulation noise by evaluating evolved networks under different noise levels.

**Data Generation:**

The raw data is generated by the C program:

```text
sims/evolved_J_evaluation/src/calc_all_J_x_noise/all_J_trial_eval_noise.c
```

The CSV files are initially generated under:

```text
under_noise_fitness/evo_sigma_{evo_sigma}/sim_sigma_{start}_{end}_step_{step}/gen_{gen}/
```

After generation, manually move the required CSV files directly under `under_noise_fitness/`, since the plotting script reads CSV files from that directory.

**Script:**

- `plot_zero_fitness_ratio_vs_sim_sigma.py` — Plot the ratio of zero-fitness individuals against simulation noise strength, with lines overlaid for each evolution noise strength.

**Input Format:**

- CSV files with filename pattern:

```text
trial_fitness_gen=200_ind=0_evo_sigma=*_sim_sigma=0.000_0.400_step_0.010_seed=...csv
```

- Columns:

```text
0_fitness, 0.01_fitness, 0.02_fitness, ...
```

Each column corresponds to a different simulation noise strength.

**Usage:**

```bash
python3 plot_zero_fitness_ratio_vs_sim_sigma.py \
  --input-dir . \
  --output zero_ratio_overlay.png
```

The script automatically scans the CSV files and overlays lines for each `evo_sigma` value.

## Data Requirements

Most scripts expect data from `sims/evo_sim/results/` in the structure:
```
data_sigma_only/ver1/
├── sigma_0.005/evo_sim_data/data,sigma=0.0050,...csv
├── sigma_0.010/evo_sim_data/data,sigma=0.0100,...csv
└── ... (other sigma values)
```


## Dependencies

- `pandas` — CSV reading and data manipulation
- `matplotlib` — Plot generation
- `numpy` — Numerical operations
