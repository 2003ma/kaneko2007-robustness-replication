# evo_sim

This directory contains the C implementation of the evolutionary simulation of gene regulatory networks.

The code simulates stochastic gene expression dynamics, applies mutation and selection to regulatory matrices \(J\), and saves evolved networks and related simulation outputs.

## Overview

This simulation is based on the evolutionary gene regulatory network model proposed by Kaneko (2007).

In this model, the regulatory matrix \(J\) is treated as the genotype. Gene expression dynamics are simulated under stochastic noise, and fitness is evaluated from the resulting expression pattern. Mutation and selection are then applied repeatedly to evolve a population of regulatory networks.

This code was used as part of a replication study of Kaneko (2007). It is a research script rather than a general-purpose software package.

## Directory structure

```text
evo_sim/
├── bin/
├── main/
├── src/
├── results/
│   ├── data_sigma_only/
│   └── ver1/
├── Makefile
└── README.md
```

- `src/`: Source code for the evolutionary simulation.
- `main/`: Main programs for running simulations.
- `bin/`: Compiled executables.
- `results/`: Output files generated by simulations.
- `results/ver1/`: Simulation results grouped by noise strength `sigma`.
- `results/data_sigma_only/`: A reduced data directory containing only selected CSV files required for later analysis.

## Source files

The main source files are:

- `kaneko_robustness.c`, `kaneko_robustness.h`: Core implementation of the stochastic gene expression dynamics, fitness evaluation, mutation, and selection.
- `save_all_J.c`, `save_all_J.h`: Functions for saving regulatory matrices \(J\) of all individuals in the population.
- `Makefile`: Build settings for compiling the simulation programs.

## Build

To compile the programs, run:

```bash
make
```

Compiled executables are generated in the `bin/` directory.

To remove compiled files, run:

```bash
make clean
```

## Output directory structure

Simulation outputs are stored under `results/ver1/`, separated by evolution noise strength `sigma`.

Each `sigma_xxx/` directory contains the main evolutionary simulation outputs in `evo_sim_data/` and additional repeated-evaluation results in `trials10000/`.

```text
results/
└── ver1/
    ├── README.md
    ├── params.txt
    ├── sigma_0.005/
    │   ├── evo_sim_data/
    │   │   ├── data,sigma=0.0050,dt=0.005,pop=300,L=300,meas=2000,relax=16000,seed=....csv
    │   │   ├── best_J,sigma=0.0050,dt=0.005,pop=300,L=300,meas=2000,relax=16000,seed=....csv
    │   │   ├── worst_J,sigma=0.0050,dt=0.005,pop=300,L=300,meas=2000,relax=16000,seed=....csv
    │   │   ├── gen_0_all_J_sigma_0.005_dt0.005.csv
    │   │   ├── gen_20_all_J_sigma_0.005_dt0.005.csv
    │   │   ├── gen_40_all_J_sigma_0.005_dt0.005.csv
    │   │   ├── ...
    │   │   └── gen_200_all_J_sigma_0.005_dt0.005.csv
    │   └── trials10000/
    │       └── ...
    ├── sigma_0.010/
    │   ├── evo_sim_data/
    │   └── trials10000/
    ├── sigma_0.040/
    │   ├── evo_sim_data/
    │   └── trials10000/
    └── ...
```

The file `results/ver1/params.txt` records parameter settings used for the simulations.

## Reduced data directory

The directory `results/data_sigma_only/` is prepared for later analysis scripts.

It contains only selected `data,sigma=...` CSV files while preserving the directory structure needed by the analysis code.

See `results/data_sigma_only/README.md` for details.

## Notes on implementation

This code is a research script rather than a general-purpose software package.

The implementation was written to reproduce and analyze the main qualitative behavior of the model. Some parameters and file paths may be specified directly in the source code or Makefile.

Because the simulation includes stochastic dynamics, results may depend on random seeds and parameter settings.
